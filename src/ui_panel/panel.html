Remove a file from git history

Path relative to the repo root, with / — a pasted absolute Windows path inside the repo is converted automatically. do it runs the command in the Git Bash terminal; commands that rewrite history or overwrite the remote ask for confirmation first.

1. Install

Fast and safe; officially recommended by git. Requires Python.

python -m pip install --user git-filter-repo

The commands below use python -m git_filter_repo, which works even when pip's Scripts folder is not on PATH (git: 'filter-repo' is not a git command). If it is on PATH, git filter-repo is the same thing.

2. Rewrite history

A single file or a folder (end it with /):

python -m git_filter_repo --force --invert-paths --path

Or every file matching a glob pattern (e.g. *.pfx):

python -m git_filter_repo --force --invert-paths --path-glob

--force skips the "not a fresh clone" refusal (you made a backup in step 0). It ends with a git reset --hard, so uncommitted changes are lost.
filter-repo removes the origin remote on purpose; add it back:

git remote add origin

1. Rewrite history

No install needed, but slow on big repos. Works for files and folders.

git filter-branch --force --index-filter "git rm -r --cached --ignore-unmatch " --prune-empty --tag-name-filter cat -- --all

2. Drop the backup refs and the old objects

git for-each-ref --format="delete %(refname)" refs/original | git update-ref --stdin
git reflog expire --expire=now --all
git gc --prune=now --aggressive

No history rewrite: the file is removed from the next commit but kept on disk. Older commits still contain it — use one of the other tabs if it must disappear completely.

1. Remove it from the index

git rm -r --cached

2. Ignore it

echo  >> .gitignore
git add .gitignore

3. Commit and push

git commit -m "stop tracking removed file"
git push
